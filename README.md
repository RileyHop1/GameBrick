# GameBrick

## Introduction

The GameBrick is a small embbeded project with the goal of making a GameBoy like device
that can play a tetris clone(that lives in a different repo). Bellow will be all sort
of helpful items that will help any curious copy-cats recreate what I have done.




## Hardware

### Micro Controller

The micro controller that is use for this project is the NUCLEO-F411RE STM32 Nucleo-64
A helpfull source that I used for this project is [Documentation](https://www.st.com/en/microcontrollers-microprocessors/stm32f411/documentation.html).
